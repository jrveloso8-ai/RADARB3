0. PRINCÍPIO NÃO-NEGOCIÁVEL (vale para toda e qualquer correção deste plano)
===============================================================================
Este sistema exibe números que pessoas podem usar para decidir uma operação financeira real.
A partir de agora:
- Nenhum valor financeiro pode ser um literal fixo/estimado apresentado como se fosse dado real
  de mercado, sem que a tela deixe isso explícito.
- Quando um dado real não está disponível, o comportamento correto é mostrar "N/D" (ou
  isViable:false, ou null, conforme o padrão que o próprio projeto já usa em alguns lugares) —
  NUNCA um número plausível "seguro" para não deixar a tela feia.
- Se um valor é uma estimativa/heurística (ex.: IV aproximada, score proprietário), ele PODE
  continuar existindo, mas a tela precisa rotulá-lo como estimativa, não como dado real/ao vivo.
- Não copie o padrão ruim de um arquivo para "resolver rápido" outro arquivo. Copie o padrão BOM
  que já existe no próprio projeto (ver seção 1).
